Cookie 🍪
📋 Sobre o projeto

O Cookie é um sistema de cadastro de clientes desenvolvido em Java SE, utilizando uma interface gráfica construída com Java Swing e arquitetura baseada no padrão MVC (Model-View-Controller).

O projeto utiliza MySQL para persistência dos dados e JDBC para realizar a comunicação entre a aplicação Java e o banco de dados.

🏗️ Arquitetura

O projeto utiliza o padrão MVC (Model-View-Controller) para organizar suas responsabilidades.

src/
├── model/
├── view/
└── controller/
Model

Responsável pela representação dos dados e pela comunicação relacionada à persistência.

View

Responsável pela interface gráfica desenvolvida com Java Swing.

Controller

Responsável pela lógica de controle e pela comunicação entre a interface e as demais partes da aplicação.

🗄️ Banco de dados

O sistema utiliza MySQL para armazenar os dados dos clientes.

A conexão com o banco é realizada através do JDBC (Java Database Connectivity).

💻 Como executar
Instale o Java JDK.
Instale e configure o MySQL.

Configure as credenciais de conexão no projeto.
